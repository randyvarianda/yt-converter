# Surface brief: converter page (static/index.html)

Scope: the only app surface. Mode: Operate. Replaces the previous flat card UI (user-approved redesign).
Audience/job: the author on their Mac; paste link, pick MP3/MP4/both + quality, convert, reveal in Finder. Speed of the task beats ornament.
Constraints: crisp, high-contrast minimal skeuomorphism; user rejects mushy neumorphism and anything slower to use. All existing functions and API stay.

## Direction contract

THESIS: The converter is a hi-fi component you operate, a faceplate, not a web form; it refuses the centred card holding a form.
OWN-WORLD: brushed anodised faceplate (silver light / graphite dark), recessed black glass VFD window glowing ice-blue, white piano keys with hard top highlights that latch down, interlocking preset keys, blue LED pips, engraved small-caps legends, seven-segment numerals.
STORY: paste link, the display shows the video; latch MP3/MP4; press a preset per format; hit the transport key; the level meter and readouts track it; saved files list on the display, each with an eject key that reveals it in Finder.
FIRST VIEWPORT: one rack-proportioned faceplate; display window left two thirds, big transport key right; key bank across the bottom.
FORM: hi-fi component faceplate, #1 on my ordered list (pick card); seed 0678eca3.
